# Homebrew tap

Formulae for [roxguel](https://github.com/roxguel)'s tools.

```bash
brew tap roxguel/tap
brew install roxguel/tap/gdt
```

Or in one step: `brew install roxguel/tap/gdt`.

| Formula | What it is |
|---|---|
| `gdt` | [Godot Development Tools](https://gdt.roxguel.dev): version manager, addon manager and test runner for Godot. macOS and Linux, arm64 and Intel. |

The formulae install the binaries from each project's GitHub releases, checked against the SHA-256 in the formula. gdt's releases also carry build attestations; see [how to verify a download](https://gdt.roxguel.dev/installation/verify/).

This tap is not affiliated with Homebrew.
